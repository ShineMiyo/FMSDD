## 더 깊게 운영하고, 더 오래 기억하는 커리어

FMSDD는 Football Manager 커리어를 위한 Windows 로컬 데스크톱 도구입니다. 소유한 클럽을 운영하고 선수 훈련과 팀 활동을 계획하며, 경기 외에도 자금과 인력을 관리할 수 있습니다. 선수의 성장 과정, 기억에 남는 경기와 인물 관계도 기록합니다.

기능은 현재 세이브와 게임 날짜를 기준으로 작동합니다. 경기 콘텐츠에는 ODD 가상 자금이 사용됩니다. 일부 클럽, 인물 및 훈련 기능은 버전 검증을 통과한 뒤 FM의 실제 데이터를 변경합니다. 사용 가능한 기능은 정확한 게임 빌드와 배포 플랫폼에 따라 달라집니다.

## V2.9.6cBeta · 외출 조우, 가족 화면 v3, 성인 콘텐츠 게이트

- **2.9.6c — 송금, 행동력, 신체 치수, 즉시 출산 단약** — 인물에게 현금을 보낼 수 있으며 성격, 가치관, 관계, 평판, 이전 선물에 따라 효과가 달라집니다. 부족한 행동력을 포인트당 5천만에 구매할 수 있습니다. 신체 치수는 UID별 비대칭 흐림 범위로 바뀌어 중간값으로 정확한 수치를 역산할 수 없습니다. 자녀 상점에 10억짜리 즉시 출산 단약이 추가되어 임신 중인 NPC에게 가방에서 사용하면 즉시 출산합니다.

- 가족 화면을 재구성했습니다: 부모 초상화를 40–44px 고정 열로 표시하고 배우자/연인/비밀 연인/보호자 관계 배지를 추가했으며, 자녀 카드를 프로필/성장/아카데미 3개 보기로 나눴습니다.
- 네이티브 유스 아카데미 완료 후 실제 FM CA/PA/주 포지션을 자녀 기록에 기록하고 생성된 UID를 표시합니다.
- 트라이얼 클럽 목록에 현재 감독 중인 클럽이 포함되며, 15세에 바로 아카데미에 가입하거나 먼저 트라이얼을 볼 수 있습니다.
- 네이티브 유스 훅이 준비되지 않았으면 활성화된 계획을 롤백하지 않고 읽을 수 있는 경고를 표시합니다.
- 임신 기간이 약 열 달로 늘어나고 NPC에 임신 표시와 출산 예정 범위가 표시됩니다. 출산은 앞당겨지거나 늦어질 수 있으며, 아이는 출산 후에만 가족에 추가됩니다.
- 자녀는 플레이어의 성을 따르며 이름만 입력합니다.
- 성장단은 배낭에서 여러 개를 한 번에 사용할 수 있고, 1개당 1살, 15세 이후에는 사용할 수 없습니다.
- 3년마다 자녀 축구 성장 이벤트가 3–5개의 포지션/CA/PA 선택지를 제공합니다. 함께 성장하면 능력이 오르고 놓치면 떨어집니다.
- 감정 상점, 청혼 반지, 더 많은 선물, 배낭 직접 선물/사용, 상점 카드 compact UI, 게임 시간 변경 시 생활 페이지 즉시 새로고침.
- 자산 도시/구역 그룹에서 하나를 열 때 전체 자산이 펼쳐지던 문제를 수정했습니다.

## V2.9.3Beta · 더 안전한 일괄 구매, 수령 가능한 자산 차량과 읽기 쉬운 기록

- 도시 일괄 구매 팝업에 사용 가능 자금과 부족액을 표시합니다. 부족액은 표시하지만 최종 자금 확인은 서버가 담당해 오래된 클라이언트 잔액이 정상 구매를 막지 않습니다. 자금 부족 시 명확한 사유를 반환하고 실패하면 전체 롤백과 환불을 유지합니다.
- 차고 일괄 관리 footer가 낮은 창에서도 팝업 안에 완전히 표시되고, 차량 목록만 스크롤됩니다.
- 보관 차고 용량이 **10,000**으로 늘어나며 기존 저장은 자동 이전됩니다. 모든 언어의 용량 문구도 갱신했습니다.
- 자산 등급 2–6에 클래식 차량 5대를 추가했습니다. 등급 달성 후 시즌 패스 카드에서 직접 수령하며, 보관 차고 → 다른 빈 차고 순서로 배정하고 모두 가득 차면 명확한 실패를 안내합니다.
- 플레이어 프로필을 재구성했습니다. 속성 기록에서 `asset_level`, `asset-level:7` 같은 내부 코드를 제거하고 읽기 쉬운 등급/차량 보상으로 표시합니다. 평판은 FM 실시간 읽기를 제거하고 외모/능력/매력/EQ와 같은 분배 속성으로 바꾸며, 1포인트당 **5 속성 포인트**를 소모합니다. 금색 테두리와 글자는 유지하고 FM 표시는 제거했습니다. 프로필은 신원/속성 2열, 금색 평판 카드, 포인트 비용 태그, 하단 고정 저장 바로 재구성했으며 기존 저장은 마이그레이션 포인트로 사용 가능 포인트를 유지합니다.

## V2.9.2Beta · 뽑기 배치, 차고 일괄 관리와 시즌 패스형 자산 등급

- 미스터리 차고 배율이 각 풀 제목 오른쪽으로 이동했고 1회/10회 버튼이 돌아왔습니다. 배율은 두 버튼에 동시에 적용되며(1회 ×N, 10회 ×10N), 1–1000회를 10회 묶음 가격으로 계산합니다. 보관/일괄 차고에서 빈자리가 생기면 뽑기 버튼이 즉시 갱신됩니다.
- 차고 일괄 관리 목록은 독립적으로 스크롤되고, 선택 가치와 이동/판매 footer는 고정됩니다. 차량 선택 시 목록을 다시 만들지 않으며 보관 차고 선택도 스크롤 위치를 유지합니다.
- 차고 상세, 보관 차고, 일괄 관리에서 중복 차량을 한 번에 판매할 수 있습니다. 모델별로 가장 비싼 한 대만 남기고 나머지를 서버 트랜잭션으로 판매하며 실패 시 롤백합니다.
- 자산 등급은 가로 시즌 패스 보드로 재구성했습니다. 현재 등급 엠블럼, 진행도, 차량 이미지가 있는 등급 카드, 잠금/대기/수령 상태, 드래그·휠·방향키·버튼·터치 스크롤을 지원하며 텍스트는 선택되지 않습니다.

## V2.9.1Beta · 다중 관계선, 일괄 운영과 차고 확장

- 친구 단계 이후 플레이어와 NPC의 성별 조합에 따라 관계선이 갈립니다. 연애선(썸→연인→부부) 또는 친구선(파트너→동호→베스트 프렌드/형제→의형제)을 선택하며, 첫 단계에서 선택이 고정됩니다. 관계 등급과 별개로 "남남, 어색함, 예의, 친숙함, 가까움, 찰떡, 인연" 관계 묘사를 표시합니다.
- 자산 등급은 상호작용 개요에서 플레이어 이름 오른쪽의 "자산 Lv.N" 버튼으로 이동했고, 팝업에서 마우스 휠로 12개 등급을 가로로 탐색합니다.
- 도시 지도에서 현재 도시의 미보유 필지를 유형별로 한 번에 구매할 수 있으며, 수량과 총액을 실시간 표시합니다. 한 번만 결제하고 실패 시 전체를 롤백합니다.
- 각 차고에 일괄 관리(전체 선택, 제조사/등급/희귀도 필터, 일괄 이동·판매)를 추가했고, 전시장은 현재 필터의 구매 가능 차량을 한 번에 구매하되 전시 전용 차량은 제외합니다. 미스터리 차고에는 ×1/×2/×5/×10/×100 배율을 추가했습니다.
- 도시 자산 생성에 64/96/128칸 프리미엄 차고를 추가했고, 차고 목록에서 구매한 차고 자산을 부동산 제공 주차보다 위에 정렬합니다.

## V2.9.0Beta · 관계의 결과, EQ와 자산 등급

- 친밀도가 -100에서 +100까지의 부호 있는 자원으로 바뀌고 결렬, 적대, 긴장, 냉담 등 부정 구간이 구분됩니다. 장기간 또는 심각한 부정 상태는 관계 위기를 일으키며, EQ·신뢰·남은 친밀도에 따라 복구를 시도하거나 이별·이혼을 받아들일 수 있습니다.
- "함께 밤을 보내기"로 임신이 발생할 수 있으며 30일 후 아이를 남길지 결정하는 사건이 열립니다. 아이를 남기면 지속적인 자녀 기록이 생기고, 임신을 종료하면 친밀도와 신뢰가 크게 떨어집니다.
- 비밀 관계는 "함께 밤을 보내기"와 "프라이빗 여행"으로 노출 위험이 쌓입니다. 노출되면 공개 파트너의 호감·신뢰·친밀도가 크게 하락하며, 비밀 관계를 끝내거나 공개 관계를 떠나야 합니다.
- 플레이어 프로필에 EQ 속성이 추가되어 대화, 선물, 데이트, 친밀 행동과 관계 위기 복구 결과에 영향을 줍니다. 같은 선택도 플레이어 능력치에 따라 다른 결과를 낼 수 있습니다.
- 개요에 보유 부동산과 차량 가치를 기준으로 하는 자산 등급 타임라인이 추가됩니다. 등급마다 영구 속성 포인트와 특별 차량을 보상하며, 보상은 한 번만 지급되고 차고가 가득 차면 차량이 대기 상태로 남아 자동 재시도됩니다.
- 친밀도 설명 푸터를 단일 열로 바꿔 좌우 분할로 인한 읽기 혼란을 없앴습니다.
- 지도 도시가 27곳에서 9개국 68곳으로 확장되었고 41곳의 국내외 도시가 추가되었습니다. 지형 마스크는 바다, 해안선, 강, 수역, 녹지와 공원을 피합니다.
- 제품 버전, 창 제목과 데스크톱 호스트를 **V2.9.0Beta** / `2.9.0.0`으로 동기화했고 개발 빌드 식별자는 `64-dev`입니다.

## V2.8.9eBeta · 결산 화면 재구성과 확정 관계 전용 친밀도

- 대화, 선물, 데이트, 자산 증여, 관계 진행과 친밀 행동의 결산 화면을 모두 단일 열의 독립 결과 카드로 다시 만들었습니다. 오른쪽이 비어 있던 이전 2열 껍데기, 지나치게 큰 버튼과 느슨한 간격을 없애고 인물, 결과, 대사, 행동력·성공률·친밀도, 보상과 확인 동작을 하나의 읽기 흐름으로 정리했습니다.

이 제안은 FMSDD가 플레이 콘텐츠로 무작위 생성하는 가상 제안이며, FM 게임의 구단이 실제로 보낸 이적 제안과 구분됩니다.

## 시작하기

1. **[공식 다운로드 페이지](https://fmodd.com/download)**에서 Windows 버전을 받으세요.
2. Football Manager를 실행하고 사용할 세이브를 불러오세요.
3. FMSDD를 실행해 해당 게임 버전을 선택한 뒤 현재 세이브에 연결하세요.
4. 클럽, 훈련, 활동과 경기 콘텐츠를 살펴보세요.

게임 데이터를 변경하는 기능을 처음 사용하기 전에 세이브를 백업해 주세요. Beta 버전의 호환성과 기능은 계속 조정됩니다.

| 환경 | 현재 범위 |
| --- | --- |
| 운영체제 | Windows 데스크톱 프로그램 |
| 게임 세대 | FM24 / FM26, 각 버전의 데이터 구조와 기능을 검사 |
