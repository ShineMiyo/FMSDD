# FMSDD

**Football Manager companion for Windows.** FMSDD (formerly FMODD) adds club ownership and a stock exchange, a city life layer, player relationships and a long-career record around your existing Football Manager 24/26 save.

> Current release: **V2.9.0Beta** · Windows 10/11 x64
> This build is a beta. Back up your save before using features that write native game data.

## What it does

- **Club stock exchange** — one exchange per country or region, share capital from facilities/youth/reputation, automatic share issuance, market/block/limit orders, financing and takeovers.
- **Life system** — 9 countries and 68 cities on real map tiles, property development and rent, a 425-car catalogue, a 100-slot storage garage, and a three-tier mystery garage with published odds.
- **People and relationships** — five relationship dimensions, EQ, signed intimacy, crises and consequences, and 12 asset milestones.
- **Career tools** — club management, training, activities, hall of fame, announcements and a local dashboard.
- **Interface** — 11 UI languages and a dark theme.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- Microsoft Edge WebView2 Runtime (usually included with Windows 11).
- Football Manager 24 or FM26 running with a save loaded.
- Back up your save before using features that modify native game data.

## Install

1. Download `FMSDD-V2.9.0Beta.exe` from Releases.
2. If SmartScreen appears, choose **More info → Run anyway**. The build is not code-signed.
3. Launch it and connect your running Football Manager save.

No installer and no administrator rights are required.
